\# ECS Terraform CI/CD Project



\## Project Overview

This project deploys a Dockerized Node.js application on AWS ECS Fargate using Terraform and GitHub Actions CI/CD.



\## Technologies Used

\- AWS ECS Fargate

\- AWS ECR

\- Application Load Balancer

\- Terraform

\- Docker

\- GitHub Actions

\- Node.js

\- Express.js



\## Features

\- Infrastructure as Code using Terraform

\- Dockerized Node.js application

\- CI/CD pipeline with GitHub Actions

\- Automatic deployment to ECS

\- Load balancing using ALB

\- Health check monitoring



\## Project Architecture

GitHub → GitHub Actions → Docker Build → ECR → ECS Fargate → ALB
